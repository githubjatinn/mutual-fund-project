\# Bluestock Mutual Fund Analytics

\## Capstone Project I — BSc Data Science, SPPU



\### Project Overview

End-to-end mutual fund analytics platform covering data ingestion, 

cleaning, EDA, performance analytics, dashboard and advanced analytics.



\### Folder Structure

\- data/raw/ — Raw CSVs from mfapi.in

\- data/processed/ — Cleaned datasets

\- notebooks/ — Jupyter analysis notebooks

\- scripts/ — Python utility scripts

\- sql/ — Database schema and queries

\- dashboard/ — Power BI dashboard

\- reports/ — Charts, insights, scorecards



\### Notebooks

\- 03\_eda\_analysis.ipynb — Exploratory Data Analysis

\- 04\_performance\_analytics.ipynb — CAGR, Sharpe, Alpha, Beta

\- 05\_advanced\_analytics.ipynb — VaR, Rolling Sharpe, Recommender



\### Key Findings

\- HDFC Top100 Direct scores 100/100 on composite scorecard

\- Kotak Bluechip leads 5yr CAGR at 22.06%

\- Nippon LargeCap has highest risk (VaR -1.59%)

\- Axis Bluechip safest fund (VaR \~0%)
