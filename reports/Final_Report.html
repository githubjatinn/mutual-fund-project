# Bluestock Mutual Fund Analytics

## Final Report — Capstone Project I

### Executive Summary

This project builds an end-to-end mutual fund analytics platform

covering 6 Bluechip schemes from 2012-2026.

### Key Results

- HDFC Top100 Direct: Score 100/100, Sharpe 1.091

- Kotak Bluechip: 5yr CAGR 22.06%

- Nippon LargeCap: Highest VaR risk -1.59%

- Axis Bluechip: Safest fund, VaR \~0%

- Day 1: Data Ingestion — 19,798 records fetched

- Day 2: Data Cleaning + SQLite DB

- Day 3: EDA — 10 charts generated

- Day 4: Performance Analytics — CAGR, Sharpe, Alpha, Beta

- Day 5: Power BI Dashboard — 4 pages

- Day 6: Advanced Analytics — VaR, Recommender
